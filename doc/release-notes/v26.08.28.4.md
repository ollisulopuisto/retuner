## Viritin 26.08.28.4

### The remote highlights the line the receiver is on

`chFlag` is a bitmask, and the remote read it as a value. A Denon showing search
results sends `0` for the heading, `1` for every selectable station and `9` —
`1 or 8` — for the one under the cursor, so a test for `chFlag = 8` matched
nothing on any list whose items are selectable. Which is every list worth
browsing: the remote worked, and looked like it did not.

### Click a name

Clicking a line walks the receiver's cursor to it and presses Enter — the cursor
keys, counted for you.

The stepping happens in Viritin rather than the browser, because the receiver
answers one request at a time and a tab closed halfway through would leave the
cursor somewhere nobody chose. Nothing new reaches the receiver: every step is
`CurUp`, `CurDown` or `CurEnter`, each already on the permitted list.

A screen with no cursor — Now Playing reports every flag as `0` — is left alone
rather than guessed at, since stepping from an unknown position moves the
selection somewhere nobody asked for, and on a list Enter then plays it.

### Upgrading

`viritin-update.sh` replaces the binary in place and rolls back if the new one
does not answer. Configuration is untouched, and `INIVersion` has not moved.
