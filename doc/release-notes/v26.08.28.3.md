## Viritin 26.08.28.3

### A browser remote for the receiver

With the AVR's source set to Internet Radio, the list it is showing **is**
Viritin's menu — the receiver is our client. Its own web interface exposes that
list and the cursor keys over HTTP, so Viritin now serves a page at `/remote`
(on the Web GUI port) that drives its tree from a browser, with a real keyboard
for search instead of the on-screen character picker.

Off by default. To turn it on, point `[WebGUI] RemoteAVRAddress=` at the
receiver:

```ini
[WebGUI]
Enable=1
WebGUIPassword=something
RemoteAVRAddress=192.168.10.153
```

Every command is proxied and matched in full against a fixed list of ten — a
prefix match would let `CurDown&cmd1=PutZone_InputFunction/NET` ride along, and
that switches the whole amplifier's source. The receiver's own interface has no
authentication at all, which is exactly why this one sits behind
`WebGUIPassword` and the `WebGUIIPAddress` filter.

### Search finds what you searched for

Search by keyword asked radio-browser for stations ordered by name. Since
radio-browser matches `name=` as a substring, "yle" also matches Hardstyle,
Freestyle and Mylene Farmer — and alphabetically "101.ru Mylene Farmer" came
first, with Yle Radio Suomi somewhere inside 125 pages of ten. On a remote
control that is indistinguishable from search being broken. Results are ranked
by votes now, like the popular list always was.

### Also in this build

- The stations editor can answer a LAN rather than only loopback
  (`WebGUIIPAddress` takes a comma-separated list with CIDR entries), and a
  wrong password costs a second.
- A station with no logo of its own is served the Viritin mark instead of a
  404, so the receiver shows something.
- `presets/` is re-checked weekly by GitHub Actions, which opens a pull request
  rather than committing: a station is dropped only after three consecutive
  weekly failures, so one CDN hiccup does not delete a national broadcaster.

### Upgrading

`viritin-update.sh` replaces the binary in place and rolls back if the new one
does not answer. Configuration is untouched, and `INIVersion` has not moved.
